# Leo's Workout App

A personal strength + conditioning tracker: workout plans, a master exercise index, weight/rep logging, and a built-in circuit timer for the Wednesday turf session.

Live: https://leojgray.github.io/workout-app/

## Files
- `index.html` — the app (UI + logic)
- `library.js` — master exercise index (how-tos, muscle groups, swaps)
- `program.js` — the current training cycle (the only file that changes between cycles)
- `timer.js` — the circuit timer engine (voice/tone cues, keep-awake)

Workout data (weights, reps, history) is stored only in your phone's browser — never committed to this repo.
